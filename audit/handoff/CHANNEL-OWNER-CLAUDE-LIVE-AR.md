```
1. الحاوية:  <Animated.View>  ← تضم كل النطاقات A→E (براند + بحث + كل الشرايط)
2. المصدر:   const scrollY = useSharedValue(0)
3. القارئ:   useAnimatedScrollHandler على القائمة → scrollY.value = e.contentOffset.y
4. الحركة:   useAnimatedStyle + interpolate(scrollY, [0, RANGE], [EXPANDED, COLLAPSED],
                                            Extrapolation.CLAMP)
5. الأولوية: الهيرو يتلاشى أولاً → الإحصائيات → الشرايط الثانوية
             ويفضل مثبّت: التوب بار + البحث + مدخل الفلاتر (الحد الأدنى)
```

#### ⛔ تلات فخاخ موثّقة — لازم تتفادى

| # | الفخ | ليه |
|---|---|---|

| ٢ | **`scrollEnabled` لازم يحسب وجود الهيدر** | `scrollEnabled={items.length > 0}` لوحده = هيدر محبوس في قائمة فاضية |

#### القواعد الملزمة
- **ممنوع الحذف.** الشرائح **تتنقل** جوه شجرة الهيدر — **كل `testID` يفضل زي ما هو**
