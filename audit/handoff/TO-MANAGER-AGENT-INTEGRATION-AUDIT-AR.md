# 5) 🔴 البند الوحيد المتبقي — **قرارك إنت، مش قراري**

بعد الدمج، `test:render-coverage` (حارس B2) بيفشل:

```

which is not in RENDER_CRITICAL.
```

**السبب — وهو عيب تكامل مش عيب في أي فرع:** حارس B2 بيطلب إن كل اختبار
رندر يبقى معلَن في `RENDER_CRITICAL`. واختبار `SendIcon` جاي من فرع تاني،
فحارس B2 مايعرفوش. **كل فرع بيعدّي لوحده — الفشل بيظهر في الدمج بس.**

**وليه مسبتهاش لنفسي:** جربت أضيف `components/icons.tsx` للمجموعة، فطلع
اختبارين فاشلين بدل واحد. السبب إن `exportedComponents()` بيدوّر على
`export function [A-Z]`، و`icons.tsx` **مافيهاش ولا واحدة** — `Feather`
متصدّرة بشكل تاني، والاختبار بيرندر `<Feather name="send" />` مش `<SendIcon/>`.

**القرار بتاعك (تلات خيارات):**
1. وسّع `exportedComponents()` تشوف `export const`
2. اسمح لمُدخل يعلن اسم مكوّن صراحة بدل الاشتقاق من الملف
3. سمِّ ملف الاختبار `Feather.render.test.tsx`

**أنا مش هخمّن في حارس إنت كاتبه.**
