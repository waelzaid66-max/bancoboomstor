# ٤) 🔴 اكتشاف جديد — النوع بيقول صح والتشغيل بيرسم علامة تعجب

## الآلية

`icons.tsx` بيعمل cast للمكوّن لأنواع `@expo/vector-icons` الأصلية:
```ts
type VectorIcons = typeof import("@expo/vector-icons");
export const Feather = IconBase as unknown as VectorIcons["Feather"];
```

**فـTypeScript بيتحقق من `name` مقابل `glyphMap` بتاع Feather الأصلي.**
لكن اللي بيترسم فعلًا هو **سجل lucide المحلي**. **مجموعتان مختلفتان.**

## القياس

```
أسماء Feather في النوع:              287
السجل وقت التشغيل:                   194
🔴 بتعدّي من TypeScript وترسم CircleAlert:  200
```

أمثلة: `activity` · `airplay` · `anchor` · `aperture` · `arrow-down` ·
`align-center` · `alert-octagon` …

## يعني إيه

```tsx
<Feather name="anchor" size={18} color={RED} />
```
**بيتكمبل نضيف · بيعدّي كل الحُرّاس الثابتة · وبيرسم علامة تعجب في دايرة.**

وفي الإنتاج **من غير أي تحذير**:
```ts
// icons.tsx:468-472
if (__DEV__) console.warn(`[icons] Unmapped icon "${name}"`);
return <CircleAlert size={size} color={color} style={style} />;
```
